Deskripsi
Aplikasi pelayanan administrasi kelurahan (bisa juga untuk desa) berbasis Laravel 12 dan MySQL. Warga mendaftar dengan NIK, mengajukan surat keterangan dari HP, memantau prosesnya dengan kode lacak, lalu mengunduh surat PDF bernomor resmi yang dilengkapi kode QR verifikasi keaslian.

Petugas bekerja dari dasbor yang sederhana: memproses permohonan, melayani warga di loket, mengelola data penduduk dengan impor Excel, menanggapi pengaduan, menerbitkan kabar, dan mencetak laporan bulanan. Dilengkapi landing page modern, delapan jenis surat siap pakai yang bisa ditambah sendiri, data contoh lengkap, dan panduan instalasi XAMPP.
Cara kerja
Situs publik menampilkan layanan, alur pelayanan, statistik, kabar, jam layanan, peta, dan tanya jawab. Siapa pun bisa mengecek status permohonan atau pengaduan memakai kode lacak, dan memindai kode QR di surat untuk membuka halaman verifikasi yang menampilkan nomor, jenis surat, dan nama pemiliknya.

Warga membuat akun dengan NIK dan tanggal lahir yang dicocokkan dengan data penduduk kelurahan. Setelah masuk, warga memilih jenis surat, mengisi keperluan dan isian khusus (misalnya nama usaha untuk Surat Keterangan Usaha), lalu mengunggah foto berkas. Berkas disimpan privat dan hanya bisa dibuka pemohon serta petugas. Status permohonan berjalan dari diajukan, diverifikasi, diproses, hingga selesai atau ditolak dengan catatan, dan setiap perubahan tercatat di riwayat.

Saat petugas menandai permohonan selesai, sistem membuat nomor surat urut per tahun (misalnya 012/SKD/KL-SKM/X/2026) tanpa risiko ganda, lalu surat PDF lengkap dengan kop, logo, data penduduk, isi surat dari template, tanda tangan lurah, dan QR verifikasi siap diunduh warga. Petugas juga bisa membuat permohonan langsung di loket, mengelola jenis layanan beserta template isi suratnya, mengimpor data penduduk dari CSV, menanggapi pengaduan, menjadwalkan kabar, mengatur akun petugas, serta mencetak rekap bulanan dan buku register surat keluar.

Panduan instalasi
Kebutuhan: PHP 8.2 atau lebih baru (XAMPP 8.2+ / Laragon), MySQL/MariaDB, dan Composer (Laragon sudah menyertakannya).

Ekstrak ZIP lalu pindahkan folder layanan-kelurahan ke C:\xampp\htdocs\layanan-kelurahan (atau C:\laragon\www\layanan-kelurahan).

Nyalakan Apache dan MySQL dari XAMPP Control Panel.

Jalankan setup:

Windows: klik dua kali setup.bat (atau buka Shell di XAMPP Control Panel, masuk ke folder project, lalu ketik setup.bat).
Linux/macOS: bash setup.sh
Script ini menjalankan composer install (jika folder vendor belum ada), membuat file .env, kunci aplikasi, database layanan_kelurahan, tabel, dan data contoh.

Buka http://localhost/layanan-kelurahan lalu masuk di /masuk:

Admin: admin@kelurahan.test / admin123
Petugas: petugas@kelurahan.test / petugas123
Warga: NIK 3273010101900001 / warga123
Buka Pengaturan kelurahan untuk mengisi nama kelurahan, logo, nama & NIP lurah, dan kode nomor surat. Ganti kata sandi admin.

Tanpa XAMPP: jalankan bash setup.sh lalu php artisan serve, buka http://127.0.0.1:8000.

Jika user/password MySQL berbeda, ubah DB_USERNAME dan DB_PASSWORD di file .env lalu jalankan setup lagi.

Untuk hosting: arahkan document root ke folder public/, ubah APP_URL di .env, pastikan APP_ENV=production dan APP_DEBUG=false, serta folder storage/ dan public/uploads/ bisa ditulis.
